# SilverWhisper releases

Public installers and updater manifests for [SilverWhisper](https://silverwhisper.app).

This repository hosts release **binaries and signatures only**. Application source lives in a separate private repository and is **not** mirrored here.

## Downloads

See [Releases](https://github.com/indrasantosa/silverwhisper-releases/releases) for macOS and Windows installers.

Updater clients fetch:

`https://github.com/indrasantosa/silverwhisper-releases/releases/latest/download/latest.json`
